# 딱세줄 사용 테스트 기록지 (PRD 완료 기준: 2~3명)

- 날짜: 2026-11-28 · 장소: (적기) · 진행: 박형우
- 기기: 참가자 본인 휴대폰 (없으면 진행자 휴대폰) · 주소: https://ttak-sejul.netlify.app
- 목표: 처음 쓰는 사람이 **메모 → 정리 → 카톡용 복사**를 1분 안에 끝내는가

## 진행 방법 (한 사람당 5분)

1. 주소만 알려 주고 **설명은 하지 않는다.** "회의 메모를 정리해서 카톡에 붙일 수 있게 해 보세요"라고만 말한다.
2. 메모는 참가자가 최근 회의를 떠올려 서너 줄 직접 적는다. 떠오르지 않으면 회의 화면의 [예시 넣기]를 써도 된다 (어느 쪽인지 적는다).
   - 화면 흐름: [회의 시작] → 메모 적기 → [회의 끝 · 딱세줄로 정리] → [카톡용 복사]
3. 첫 화면을 연 순간부터 [카톡용 복사]를 누를 때까지 휴대폰 시계로 잰다. **AI가 정리하는 시간도 포함한다.**
4. 도와주지 않는다. 3분이 지나거나 참가자가 포기하면 실패로 적고 그때 도와준다.
5. 끝나고 두 가지만 묻는다.
   - "어디서 멈칫했어요?"
   - "다음 팀 회의 때 또 쓸 것 같아요? (네 / 글쎄 / 아니요) 왜요?"

> 참가자 이름은 적지 않는다 (A·B·C로). 회의 메모 내용도 기록지에 옮기지 않는다.
