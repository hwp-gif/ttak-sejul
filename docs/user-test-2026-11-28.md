# 딱세줄 사용 테스트 기록지 (PRD 완료 기준: 2~3명)

9주차 「현장 검증과 성과 측정」 방식으로 진행한다: **묻고, 지켜보고, 세고, 본 만큼만 말한다.**

- 날짜: (적기) · 장소: (적기) · 진행: 박형우
- 주소: https://ttak-sejul.netlify.app · 기기: 참가자 본인 휴대폰 (없으면 진행자 휴대폰, 어느 쪽인지 적기)

## 1. 미리 정해 두기

| 항목 | 정한 것 |
|---|---|
| 과업 (참가자에게 하는 말) | "방금 끝난 회의 내용을 정리해서, 팀 단톡방에 바로 붙여 넣을 수 있게 복사해 주세요." |
| 회의 내용 | 아래 메모 카드를 보여 주고 휴대폰에 옮겨 적게 한다 (모두 같은 메모라 시간을 견줄 수 있다) |
| 성공 조건 | 도움 없이 정리 결과를 **카톡용으로 복사**함 (화면에 "복사됨 ✓") |
| 시간 재기 시작 | 첫 화면이 열린 휴대폰을 건넨 순간 |
| 시간 재기 끝 | "복사됨 ✓"가 뜬 순간 (AI가 정리하는 시간도 포함) |
| 멈추는 때 | 5분이 지나거나 참가자가 그만두겠다고 할 때 → **실패**로 적고, 그 뒤에 도와준다 |

과업 문장에는 단추·메뉴 이름을 넣지 않는다. 어떻게 하는지 힌트를 주면 지켜봐도 알게 되는 것이 없다.

**메모 카드 (지어낸 내용)**
```
다음 주 금요일 발표 자료 준비
슬라이드는 민지가 만들기로 함
발표 연습은 수요일 저녁에
예산은 다음 회의에서 다시 얘기
```

## 2. 시작할 때 하는 말

1. "이 앱을 시험하는 거지, 당신을 시험하는 게 아니에요. 막혀도 앱 문제예요."
2. "하면서 생각나는 걸 소리 내어 말해 주세요."
3. "중간에 제가 도와드리지 않을 거예요. 끝나고 다 설명드릴게요."
4. "언제든 그만두셔도 돼요."

## 3. 지켜보는 동안

- 돕지 않는다. 질문을 받으면 "어떻게 하실 것 같아요?"로 되묻는다.
- **들은 말**은 고치지 않고 따옴표로, **본 행동**은 그대로, **내 해석**은 따로 적는다.
- 참가자 이름은 적지 않는다 (P01·P02·P03).

## 4. 끝나고 묻기 (최근 경험 질문)

앞으로 쓸지, 편한지는 묻지 않는다 ("또 쓰실 거예요?", "편하죠?"는 듣기 좋은 답만 돌아온다).

1. "가장 최근 팀 회의가 끝난 뒤, 정리는 누가 어떻게 했어요?"
2. (대답을 받아서) "그때 가장 오래 걸린 건 뭐였어요?"
3. "아까 ○○에서 멈추셨을 때 무슨 생각을 하셨어요?"

"실제 대상" = 회의가 끝나면 단톡방에 정리를 올리는 팀장·서기 (PRD 핵심 사용자). 동료·가족의 기록은 그만큼 무게가 작다.

## 6. 세기와 말하기 (테스트 뒤에 채우기)

- 성공률: **_명 중 _명** (나눈 수를 함께 쓴다)
- 평균 시간: 성공한 시도만 _초 (_번) · 실패 포함 전체 _초 (_번) — 어느 시도를 넣었는지 밝힌다
- 가장 많이 멈춘 곳:
- 고칠 것 한 가지: 문제 → 근거(P0_) → 바꿀 것 → 다시 볼 것

발표·문서에서는 본 만큼만 쓴다. 3명 중 3명이 성공했어도 "사용자 대부분이 쉽게 쓴다"가 아니라 "처음 쓰는 3명 중 3명이 도움 없이 _초 안에 복사까지 했다"로 쓴다.
