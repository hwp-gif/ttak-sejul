# 딱세줄 · 회의록 3줄 요약

🔗 **배포:** https://ttak-sejul.netlify.app · **GitHub:** https://github.com/hwp-gif/ttak-sejul

회의를 시작할 때 켜 두고 편하게 적으면, 끝날 때 **핵심 요약 3줄 · 결정 사항 · 할 일 · 남은 질문**으로 정리해 주는 웹앱(PWA)입니다.
결정과 할 일마다 **메모 원문 근거**를 붙이고, 그 문장이 메모에 실제로 있는지 코드로 확인해 ✓ / ⚠ 로 보여 줍니다.

> 2026 천안형 AX 액션러닝 개인 프로젝트. 자세한 기획은 [PRD.md](PRD.md).

## 주요 기능
- **회의 흐름**: 첫 화면 [회의 시작] → 회의 중(타이머 · 줄 노트 · 화면 꺼짐 방지) → [회의 끝 · 딱세줄로 정리] → 결과 카드 (옛날 만화처럼 동그라미가 열리며 등장)
- **AI 정리**: 요약 3줄 · 결정 · 할 일(담당 · 기한) · 남은 질문, 제목을 비우면 자동 제목
- **원문 근거 ✓**: AI가 붙인 근거 문장이 메모에 있는지 코드로 검사
- **빠진 정보 알림 · 미정 바로 채우기**: 담당자 · 기한이 없으면 "미정"으로 두고, 눌러서 바로 정하기
- **정리에 안 들어간 메모 줄 표시**: AI가 빼먹은 내용 확인용
- **개인정보 경고**: 전화번호 · 이메일이 있으면 보내기 전에 가릴지 묻기
- **결과 언어 선택**: 한국어 · English · 日本語 · 中文 · Tiếng Việt (근거 문장은 원문 그대로)
- **카톡용 · 메일용 복사**, 할 일 체크박스
- **기록 저장 · 최근 회의**: 정리 결과를 Supabase(PostgreSQL)에 저장하고, 첫 화면에 **이 브라우저에서 정리한** 최근 5개를 보여 줌 (회의록이 남에게 보이지 않게 브라우저별 무작위 번호로 구분, RLS 켬)
- **마스코트 킴대리 ☕**: 1930~40년대 고전 만화 화풍으로 직접 그린(SVG) 넥타이 맨 머그잔. 머리 위 세 줄 김이 표정처럼 바뀜 (기쁨 · 고민 · 하트 · 지침)
  - 기능 옆 (?) 버튼 → 킴대리가 아래에서 말풍선 대사창으로 설명 (부드럽게 열리고 닫힘)
  - 첫 결과에서 한 번만 뜨는 안내, 기다릴 때 혼잣말, 근거가 모두 ✓면 "근거 100%" 도장, 회의 30분이 넘으면 "김이 식어 가요" 알림
  - 재미는 가장자리에만: 요약 · 결정 · 할 일과 복사되는 글은 단정하게 유지
- **앱처럼 설치(PWA)**: 폰에서 "홈 화면에 추가" → 주소창 없이 열림. 아이콘은 빈티지 햇살 무늬 위 만화 말풍선 + 세 줄 + ✓ (회의 대화 → 세 줄 → 원문 확인)
- **다크 모드**: 폰 설정을 따라 자동 전환
- 무료 AI 모델을 빠른 순서로 시도하고, 실패하면 다음 모델로 넘어감 (전체 48초 안에서만 — Netlify 함수 60초 제한)
- **사용 횟수 제한** (팀 API 키 보호): 한 사람당 1분 5번 · 하루 30번, 사이트 전체 하루 300번 (전시 기간 ~11/29는 1분 20번 · 하루 200번 · 사이트 500번, 11/30부터 자동으로 평소 기준). DB(`api_hits`)로 세고 IP는 해시로만 저장

## 실행 환경
- Node.js 22 이상, npm
- Next.js 16 (App Router) · React 19 · TypeScript
- AI: OpenRouter 무료 모델

## 설치 · 실행
```bash
git clone https://github.com/hwp-gif/ttak-sejul.git
cd ttak-sejul
npm install
cp .env.example .env   # 값을 채운다
PORT=3074 npm run dev     # http://localhost:3074
```

## 환경 변수 (`.env`, GitHub에 올리지 않음)
| 이름 | 설명 |
|---|---|
| `OPENROUTER_API_KEY` | OpenRouter API 키 (AI 정리) |
| `DATABASE_URL` | Supabase PostgreSQL 접속 주소 (기록 저장. 테이블 `meeting_logs`는 처음 저장할 때 자동 생성) |

## 테스트 예시
1. [예시 회의로 둘러보기] → [회의 끝 · 딱세줄로 정리] → 결정 · 할 일에 ✓ 원문 확인이 붙는다
2. 담당자를 적지 않은 할 일 → "담당: 미정 · 정하기 ✎"가 뜨고, 눌러서 이름을 고르면 반영된다
3. 빈 메모로 정리 → "메모를 입력해 주세요." 안내가 뜨고 AI를 부르지 않는다
